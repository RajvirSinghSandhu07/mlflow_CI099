Qualitative Analysis: Key Model Disagreements

Detailed inspection of 5 sample sentences out of the 18 disagreement cases (from outputs/disagreements.csv).

# Sentence Gold Model A Model B Winner Linguistic Commentary
1 "oh come on ." neg pos neg Model B Short text with no lexical sentiment words. Negativity is purely conveyed via exasperated tone, which RoBERTa captures.
2 "a bloated gasbag thesis grotesquely impressed by its own gargantuan aura of self-importance ..." neg pos neg Model B Insulting rare vocabulary. Model A is misled by the keyword "impressed", whereas Model B parses the sarcastic full clause.
3 "writer/director joe carnahan 's grimy crime drama is a manual of precinct cliches , but it moves fast enough to cover its clunky dialogue and lapses in logic ." pos neg pos Model B Heavy negative descriptors ("cliches", "clunky", "lapses"), but the contrastive "but it moves fast enough" flips the sentiment. B handles contrast.
4 "fun , flip and terribly hip bit of cinematic entertainment ." pos pos neg Model A "terribly" is functioning as an intensifier ("very hip") rather than criticism. Model B mistakenly treats "terribly" as negative.
5 "it 's a bit disappointing that it only manages to be decent instead of dead brilliant ." neg neg pos Model A Positive tokens ("decent", "brilliant") within overall negative evaluation. Model B gets misled by positive adjectives, whereas Model A latches onto "disappointing".

Project Architecture & Reproducibility

All models are wrapped with mlflow.pyfunc.PythonModel inside hf_wrapper.py, enabling zero-code Hugging Face inference via standard MLflow URI aliases.

# 1. Start local MLflow server
python -m mlflow server --host 127.0.0.1 --port 5000 --backend-store-uri sqlite:///mlflow.db

# 2. Run evaluation on 200 SST-2 validation sentences
python evaluate.py

# 3. Register models & set @champion / @challenger aliases based on rule
python register_champion.py

# 4. Predict using champion model loaded strictly from alias
python predict_from_mlflow.py
